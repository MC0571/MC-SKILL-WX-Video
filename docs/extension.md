# Chrome 扩展使用说明

安装方式见[项目 README](../README.md#chrome-扩展)。

商店安装版在 Chrome 确认更新已下载后显示提示；选择立即更新时，会等当前任务和扩展下载结束再安全应用。非商店版低频检查公开的稳定 `extension-v…` Release，有更新时只提醒手动更新；检查结果未知或来源不明时显示可关闭的“无法检查”提示。实际版本更新后的“已更新”提示也可关闭，确认展示后不再重复。GitHub 发布或提交商店审核不代表 Chrome Web Store 已发布该版本，商店版以 Chrome 实际提供的更新为准。

1. 在安装扩展的 Chrome 用户中登录 [腾讯元宝](https://yuanbao.tencent.com/)。
2. 点击扩展图标，在打开的页面中粘贴分享链接并解析。
3. 预览视频，查看封面、标题、作者和各版本下载链接。
4. 点击所需版本下载。页面会显示完成或中断；关闭页面不会取消 Chrome 已启动的下载。

不带查询参数的有效分享链接会作为当前用户的本地草稿保存，关闭页面或更新扩展后可恢复；清空输入框会清除草稿。解析结果和媒体认证参数不保存为草稿。

未填写链接或链接格式不正确时，输入框下方显示警告并聚焦输入框，修改输入后清除；解析失败也在同一区域提示。

扩展页还会列出最近 5 条本扩展下载，并可查看完整记录、定位仍存在的文件；Chrome 中已清除的记录也会从列表移除。记录按本地日期分组，支持收起/展开、切换时间顺序，以及今日、昨日、近 7 日、近 30 日和更早的日期筛选（更早指近 30 日之前）。最近下载与完整记录的容器随内容增减高度，超过页面可用空间时在内部滚动，上下保留留白。查看完整记录时保留解析输入框，点击页面标题可返回首页；标题旁显示当前安装扩展的 manifest 版本。未点击过仓库链接时显示“Star 一下”，循环播放 3 秒星标动画；点击后记住选择，显示“Github”并停止动画，不检测实际 Star。悬停或键盘聚焦仓库链接时立即显示 Star 引导。首次成功解析且列表已有下载记录时，商店评价提示会排在第一条下载记录之后；点击评价或关闭按钮后不再显示，不区分安装来源。鼠标移入评价卡片或键盘聚焦时显示关闭按钮，悬停或聚焦按钮立即提示“不再提醒”；触屏上始终显示关闭按钮。页面底部提供隐私政策与飞书问题和建议表单入口，表单需由用户自行填写和提交。

视频保存位置遵循 Chrome 下载设置。默认文件名是清理后的短标题和浏览器本地日期（`短标题_YYYYMMDD.mp4`）；显式相对 `.mp4` 文件名按原路径传给 Chrome，重名时由 Chrome 自动追加后缀。H.264、H.265 是编码名称；接口未返回的画质不会生成下载链接。

标题区的“Agent 设置”会展示 ChatGPT、Claude Code 与 WorkBuddy 图标及连接状态灯：已连接为绿灯，连接失败或断开为闪烁红灯，正在连接为橙灯，尚未确认为灰灯；减少动态效果时红灯不闪烁。悬停或键盘聚焦时立即显示连接说明，按 Esc 可收起。它可打开完整安装提示词，其中会自动填入当前 Chrome 用户的实际扩展 ID 和稳定实例 UUID。点击面板底部的复制按钮后，转圈图标在成功时转为绿色对勾与“已复制”，停留 2.5 秒后恢复；减少动态效果时直接切换状态。失败时显示带图标的警告卡片，并选中文本供手动复制。把提示词交给目标 Agent 即表示选定这个 Chrome 用户；AI 会按 Skill 指引检查或修复桥接并连接该实例，不需要手动查找或复制 ID。元宝已登录时收起登录提示，未登录或检查失败时仍显示对应状态。
