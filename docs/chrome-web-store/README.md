# Chrome Web Store 素材

## 上架文案

**名称**：视频号分享链接解析与下载

**简短说明**：零隐私风险的视频号本地解析器，为内容创作者与 AI 自动化工作流打造。

**详细说明**：

如何安全地把视频号内容变成你的本地素材，甚至直接喂给你的 AI 助手？这款扩展为你提供了一条零凭证泄露风险、完全可控的本地通道。

为什么选择它？

你的账号，始终由你掌控：市面上的解析工具往往要求授权或托管 Cookie，隐患重重。本扩展直接调用你当前 Chrome 浏览器中的腾讯元宝会话，扫码与验证均由你亲自在浏览器内完成，无需把登录信息交给任何 AI 助手或外部平台。

为 AI 装上“视频号提取技能”：不想手动复制粘贴？支持在 macOS 与 Windows 上一键接入本地 AI 助手。只需将项目提供的安装说明丢给你的 AI，即可让它自主完成配置，从此一句话让 AI 帮你从分享链接拉取视频。

纯净、直观的本地体验：粘贴链接即可核对封面、标题与创作者，按需挑选原始预览提供的视频版本，通过 Chrome 原生下载器直达本地目录，干净无广告。

边界与声明

使用前需在当前 Chrome 保持腾讯元宝登录状态。

仅提取分享预览实际提供的视频流，不提供解密、重编码或批量抓取功能。请仅用于您有权使用的合规内容。

## 设计说明

主要设计选择：

- **颜色**：以微信绿 `#07C160` 和视频号黄 `#FA9D3B` 建立品牌识别，文字使用深墨 `#10291B`，避免在品牌色块上使用对比不足的白字。深墨与绿、黄橙、白底、浅底 `#F5FAF6` 的对比分别为 6.50:1、7.34:1、15.50:1、14.68:1，均达到 WCAG AA 普通文字要求。
- **字体**：用粗体中文标题建立阅读入口，较轻的说明文字留出层级；宣传图文案保持短句，以便在缩略尺寸阅读。
- **标志**：宣传图和截图侧栏直接引用权威矢量标志 `docs/images/logo.svg`，不重画标志几何；侧栏顶部加白色底块，避免绿色标志融入绿色标题区。导出器把 SVG 源内的相对图片引用以内嵌数据 URL 提供给 Sharp，以便在 PNG 中保留矢量标志的清晰度。
- **构图**：宣传主标题突出“轻松下载视频号内容”，主视觉使用正式的绿框黄袋标志；宽幅图补充 AI 助手接入和登录信息留在浏览器，小幅图保留相同卖点。
- **间距**：标题、品牌标识和图形之间留出独立空间，边缘保留安全距离，缩小后不让主要符号贴边。
- **截图**：三张原始界面图为 1280 × 1000，按原比例缩放到画布右侧 1024 × 800；左侧 256 像素绿色标题区使用深墨文字，黄橙色标记重点，并标注“示例数据”。不加外侧留白、卡片包装、假浏览器外壳或圆角裁切，也不拉伸、裁切实际界面。

三个截图分别展示解析输入、AI 助手接入和登录信息说明。

界面合成上的小标题与示例数据标记均位于独立 SVG 源文件中。SVG 字体栈中拉丁字符优先使用 Arial；不包含的中文字形由系统中文字体回退，当前 macOS 使用 PingFang SC。交付 PNG 在当前 macOS 环境生成。跨系统重现需提供等效中文字体，否则字形、换行或字宽可能因系统替代字体而变化。

## 验证与规范

- **维护者与接入条件**：Chrome 扩展需要 Chrome 116 或更新版本；可选 Skill 还需 macOS 或 Windows、Node.js 22.22.2 或更新版本，以及在 Chrome 所在机器运行的本地 Native Messaging 桥接。正常使用扩展不要求安装 Skill。

- 对照 Chrome 官方[商店图片说明](https://developer.chrome.com/docs/webstore/images)：小型宣传图为 440 × 280，大型宣传图为 1400 × 560；图片以完整画幅展示。
- 对照官方[优质商店详情页建议](https://developer.chrome.com/docs/webstore/best-listing)：截图以实际产品体验为主，使用 1280 × 800 或 640 × 400 画布，避免边框、圆角裁剪和过多文字；宣传图需在缩小后仍易读。
- 使用 `export-assets.cjs` 导出 PNG 和总览，并逐张断言上架尺寸及不透明度。它会把 SVG 引用的本地标志和截图嵌入数据 URL 后交给 Sharp 渲染。脚本需要 Node.js 与环境中已有且可加载的 `sharp`（本次使用 `sharp` 0.35.5，没有添加 npm 依赖）：

  ```sh
  NODE_PATH=<已有 sharp 的 node_modules 路径> /Volumes/2T/.codex/bin/external-dev <Node 可执行文件> docs/chrome-web-store/export-assets.cjs
  ```

- 本次中文字体由当前 macOS 的 PingFang SC 回退提供。跨系统重导需要可用的等效中文字体；否则字形宽度或换行可能改变。
- 导出后核对 PNG 像素尺寸，并查看 50% 缩小预览检查标题和关键符号的可读性。
